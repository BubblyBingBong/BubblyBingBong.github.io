01 Research

  1. ICML 2026Main conference

    CaP-X: A Framework for Benchmarking and Improving Coding Agents for Robot Manipulation

    Max Fu*, Justin Yu*, Karim El-Refai*, Ethan Kou*, Haoru Xue*, Huang Huang, Wenli Xiao, Guanzhi Wang, Fei-Fei Li, Guanya Shi, Jiajun Wu, Shankar Sastry, Yuke Zhu, Ken Goldberg, Linxi “Jim” Fan *equal contribution

    A code-as-policies method and benchmark for generalizable robot control, paired with an RL gym for GRPO-based LLM training. I helped build the first benchmark for evaluating LLMs and VLMs on embodied reasoning through robotic code generation, spanning multiple API abstractions and tasks drawn from Robosuite, LIBERO, and BEHAVIOR — plus an agentic harness using a model ensemble and skill library that outperforms SOTA models on it. In collaboration with Stanford, CMU, and NVIDIA.

    Runyu Lu*, Yubo Wu*, Ethan Kou*, Letian Fu, Wenli Xiao, Ajay Mandlekar, Yinzhen Xu, Guanya Shi, Ken Goldberg, Ang Chen, Mosharaf Chowdhury, Yuke Zhu, Linxi “Jim” Fan, Guanzhi Wang *equal contribution

  3. Open source500+ downloads · 10 citations

    Extended Kalman Filter State Estimation for Autonomous Robots

    Ethan Kou*, Acshi Haggenmiller

    A robotic simulator built on a self-derived kinematics motion model, with Jacobian-based EKF covariance propagation for sensor fusion and Monte Carlo trials evaluating localization accuracy.
